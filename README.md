# 한양대 면접 공부 PWA (iPhone / iPad / Windows)

Mac 없이 iPhone에서 쓰기 위한 웹앱(PWA) 버전입니다. 최신 2026-09-16 PC 버전의 `study_schedule.json`, 순차 잠금, 49단계 일정, HTML/PDF 교재 흐름을 옮겼습니다.

## iPhone에서 쓰는 가장 쉬운 방법

PWA는 `file://`로 직접 열면 설치/오프라인 기능이 제대로 작동하지 않습니다. 이 폴더를 HTTPS 웹사이트에 한 번 올린 뒤 Safari로 접속해야 합니다.

### 방법 A — GitHub Pages (무료)
1. GitHub에서 새 저장소를 만듭니다.
2. 이 ZIP의 파일을 저장소 최상위에 업로드합니다.
3. 저장소 `Settings → Pages`에서 `Deploy from a branch`, `main`, `/ (root)`를 선택합니다.
4. 생성된 `https://...github.io/.../` 주소를 iPhone Safari에서 엽니다.
5. Safari 공유 버튼 → `홈 화면에 추가`를 누릅니다.

### 방법 B — Netlify Drop 같은 정적 호스팅
이 폴더 전체를 정적 사이트로 배포하고 나온 HTTPS 주소를 Safari에서 연 뒤 `홈 화면에 추가`합니다.

## 포함 기능
- 2026-09-16 시작 7주×7일 49단계
- 5개 항목 완료 전 다음 단계 잠금
- 밀린 단계 우선 진행
- 미래 날짜 잠금
- 완료 체크 / 날짜별 메모 / 달력 상태
- 어제 미완료 표시
- 열린 장만 `lessons.html?unlocked=...`로 열기
- 전체 HTML / PDF 참고 교재
- 홈 화면 설치 및 오프라인 캐시
- 진행 기록은 해당 iPhone의 브라우저 `localStorage`에 저장

## 알림 주의
`60분 뒤 알림`은 브라우저/PWA가 실행 상태를 유지할 때는 동작하지만, iOS가 웹앱 프로세스를 완전히 종료하면 JavaScript 타이머가 중단될 수 있습니다. 앱이 종료돼도 확실하게 도착하는 알림은 HTTPS 서버에서 Web Push를 보내는 기능을 추가해야 합니다.

## 기록 백업
현재 버전은 서버 동기화가 없습니다. Safari 사이트 데이터 삭제, 브라우저 초기화 등을 하면 기록이 사라질 수 있습니다. 추후 iCloud/서버 동기화를 붙일 수 있습니다.

## 2026-09-16 PC HTML 디자인 동일 버전
- `lessons.html`은 Windows PC 버전에서 실제로 열리던 **전체 독립형 HTML 교재 원본**을 그대로 사용합니다.
- 따라서 PC에서 보이던 상단 영웅 영역, 검색/글자 크기/다크모드 도구막대, 목차, 본문 카드, 코드 블록, 표, 퀴즈, 학습상태 UI가 iPhone에서도 동일한 HTML/CSS로 표시됩니다.
- iPhone의 화면 폭이 좁을 때는 원본 HTML에 이미 들어 있던 반응형 규칙에 따라 왼쪽 목차가 본문 위로 이동합니다. 색상·타이포그래피·본문 구성은 바뀌지 않습니다.
- PWA의 `현재 교재 열기`/`열린 장 보기`는 기존과 같이 `?unlocked=...`를 전달하므로 순차 잠금도 PC 교재 자체에서 유지됩니다.
- 기존 PWA를 이미 설치했다면 새 파일을 GitHub에 올린 뒤 Safari/PWA를 한 번 완전히 닫았다 다시 열어 새 Service Worker(v3)를 받으세요.
